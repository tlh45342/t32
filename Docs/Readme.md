T32 Documentation

This directory contains the architectural documentation for the T32 virtual
processor.

The documentation is considered the authoritative specification for the
instruction set, programmer's model, execution environment, and testing
strategy.

When an implementation differs from this documentation, the documentation
defines the intended behavior and the implementation should be corrected.
